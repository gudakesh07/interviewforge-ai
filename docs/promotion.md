# Promotion Checklist

Use this checklist after publishing the repository.

- Add repository topics: `fastapi`, `python`, `interview-preparation`, `ai`, `sqlite`, `sqlalchemy`, `open-source`.
- Pin the repository on the GitHub profile.
- Add screenshots or a short demo video to the README.
- Publish a first release: `v0.1.0`.
- Share a concise post on LinkedIn, Telegram, X, Reddit, and relevant Python/FastAPI communities.
- Create issues labeled `good first issue`.
- Keep the README honest, visual, and easy to run.
